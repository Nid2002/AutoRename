======================================================
AutoRename Phoenix v1.0
======================================================

Obrigado por utilizar o AutoRename.

Esta aplicação renomeia automaticamente boleto de condomínio em PDF.

------------------------------------------------------
Primeira utilização
------------------------------------------------------

1) Abra o arquivo:

config.ini

2) Caso necessário altere as pastas:

PASTA_ENTRADA
PASTA_LOGS

3) Salve o arquivo.

------------------------------------------------------
Como utilizar
------------------------------------------------------

1) Coloque os PDFs na pasta:

Entrada

*OBS: Caso deseja colocar um endereço ex: "C:\%user%\Desktop" ai todos os boletos que estiverem nesse diretório e que sejam boletos condominiais serão renomeados, mas a melhor sugestão é ter uma pasta especifica para esse trabalho.

2) Execute:

AutoRename.exe

3) Aguarde o processamento.

4) Os arquivos serão renomeados automaticamente.

------------------------------------------------------
Logs
------------------------------------------------------

Caso ocorra algum problema consulte:

Logs\autorename.log

Se necessário altere no config.ini:

DEBUG = True

Isso fará com que o programa registre todas as etapas da extração.

------------------------------------------------------
Problemas conhecidos
------------------------------------------------------

• O PDF não pode estar aberto durante a renomeação.

Caso esteja aberto o Windows impedirá a alteração do nome do arquivo.
