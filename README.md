## About

AutoRename is a cross-platform utility designed to automate repetitive file renaming tasks by extracting information directly from documents.

Instead of relying only on existing filenames, AutoRename analyzes document content to generate consistent and meaningful filenames, reducing manual work and minimizing errors.

Originally created to solve real-world document workflows, the project focuses on simplicity, reliability, and efficiency.

## ✨ Features

- 📄 Intelligent document-based renaming
- ⚡ Fast batch processing
- 🛡️ Dry Run mode for safe testing
- 📝 Detailed execution logs
- ⚙️ Configurable behavior
- 💻 Windows and Linux support
- 📦 Standalone executables
